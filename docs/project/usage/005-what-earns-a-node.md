## Do
Make a node for something someone could agree with, argue against, or be blocked by: an option, a decision, a criterion, an open question, a tension, a constraint, a deliverable with an owner.

## Don't
Don't make a node for a passing remark, a restatement of an existing node, or a topic nobody took a position on. A graph of everything mentioned is as useless as no graph.

## Example
```bash
umx node add --type tension --title "Speed versus auditability"
```

## Why
The value of the graph is what is contested and what blocks what.
